HealthCheck ODS 3: Saúde e Bem-Estar

Descrição do Problema

Muitas pessoas não monitoram sinais básicos de saúde diariamente. Isso dificulta prevenção e acompanhamento de condições como estresse, hipertensão e taquicardia.

Justificativa

O HealthCheck visa garantir saúde e bem-estar para todos. Uma ferramenta simples, acessível e que funcione offline pode ajudar usuários a acompanhar sua saúde sem depender de serviços complexos.


Público-Alvo

Pessoas que desejam monitorar indicadores básicos.

Indivíduos com rotina estressante.

Usuários que buscam autocuidado simples e acessível.


Objetivo do App

Criar um registro diário de saúde, com monitoramento de:

Batimentos

Pressão arterial

Humor

Histórico local


Tipo de Aplicativo

PWA Progressive Web App
Funciona no navegador, pode ser instalado e roda offline.


Como Rodar o App
Método 1 Abrir direto

Baixe os arquivos:
index.html, manifest.json, service-worker.js, icon.png

Abra index.html no navegador
Isso já funciona 100%.


Método 2 Usar servidor local (recomendado para funcionar como PWA)

Se quiser instalar como app:

Instale o servidor:

npm install -g http-server


Rode:

http-server .


Acesse:

http://localhost:8080


Clique em Instalar no navegador.
